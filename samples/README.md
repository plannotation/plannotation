# PlanLabel samples

Landing in **Phase 4**, generated by `make samples` — nothing here is committed by
hand, and regeneration is byte-for-byte reproducible apart from timestamps.

Three seeded IFC4 models, each exported to a labelled sheet:

| Sample | Sheet | Contents |
| --- | --- | --- |
| `floorplan` | Architectural plan | Walls, doors, windows, one storey, grid A–D / 1–4 |
| `positionsplan` | Structural position plan | Columns, beams, a slab tagged `Pos. 1…n`, grid |
| `section` | Building section | Two storeys with levels |

Each directory holds `model.ifc`, `sheet.svg`, `sheet.pdf`, `sheet.labelled.pdf`,
`labels.json` and `groundtruth.jsonl`. Every sample is expected to validate at
conformance level **L3** with zero errors, and `sheet.labelled.pdf` must rasterise
identically to `sheet.pdf`.
