Plannotation

Spec GitHub

Plannotation attaches a JSON file, a plannotation, to each page of a PDF drawing without changing the page. It records what the page shows: sheet, viewports and scale, IFC elements with GlobalId and outline, dimensions, grids, levels, marks and callouts.

The outlines are drawn from each sheet's plannotation. Open a sheet to inspect it.
